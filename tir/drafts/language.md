### Compound vowels

| Bauhinian | Latin | Sound-alike                                                                       |
| --------- | ----- | --------------------------------------------------------------------------------- |
| ئاۋ       | aw    | b**au**hinian. Just this one place. I don't permit this to be used anywhere else. |
| ئاي       | ai    | t**y**pe (note how the second letter is a "y" but is spelled "i" in Latin)        |
| ئەي       | ei    | s**ay**                                                                           |
