### 帝

<dl>
<dt>场所</dt>
<dd>宫殿里有个公开区域专门来干这事的</dd>
<dt>动物</dt>
<dd>龙</dd>
<dt>关联</dt>
<dd>紫荆花、权力</dd>
<dt>紫荆语</dt>
<dd>لا خوككسا</dd>
</dl>

{% image "god seal" 200 "帝章" 'float-right' %}

世界最顶端的上帝。你的一言一举、每一个想法，实际上都是**帝**决定的。看来古代紫荆人大多都主张决定论呀。

紫荆帝国的皇帝是**帝**的使者。君权神授，只要皇帝持有**龙帝章**他就有统治朝廷的权力。这枚印章传说是**帝**唯一亲手创造的物品。**帝**使皇帝的权力有效，并认可天子。非常凑巧的是**帝**所认可的皇帝和天子都是男的，真是一场意外的巧合呀。

{% image "law seal" 200 "律章" 'float-right' %}

**律**就是法律。**律**给你下达审判时，你不能抗拒。古时的**律**基本上是跟**帝**一起保障皇帝的权力的，现代的说法则更注重于阐明普通人如何无力抵抗**律**的判决。

### 响

<dl>
<dt>场所</dt>
<dd>自己房间里，关门拉窗帘</dd>
<dt>动物</dt>
<dd>飞蛾</dd>
<dt>关联</dt>
<dd>盯梢、摄像头、窃听器、监视器</dd>
<dt>紫荆语</dt>
<dd>لا ئەككو</dd>
</dl>

{% image "echo seal" 200 "响章" 'float-right' %}

**响**正趴在你的屋檐下呢。还在墙上。也在桌子底下、床底下、地板里。**响**一直在听，你的一言一语、一举一动。你的秘密在**响**面前一览无遗。

在古代，**响**一直是一个善良的神，最理解你的好知己。在现代，有些有争议的作品则把**响**比作无所不在的国家监视体系。

小孩写日记打头都是“亲爱的响”，但这在没意思的[伟思德维亚](#伟思德维亚)里算违法。

父母也有时会跟小孩说诸如“你要关灯后打手电筒看书，响可是会看见的！”

### 摹

<dl>
<dt>场所</dt>
<dd>图书馆、档案室</dd>
<dt>动物</dt>
<dd>丹顶鹤</dd>
<dt>关联</dt>
<dd>书籍、纸张、卷轴、书架、墨</dd>
<dt>紫荆语</dt>
<dd>لا كاپې</dd>
</dl>

{% image "copy seal" 200 "摹章" 'float-right' %}

创世神。**摹**是一个抄写员、史官、档案管理员。从历史的开端到最新的进展，她把一切都要记录在自己无限的档案室里。有时说不定**响**还会跟**摹**爆一些料，但一般情况下**响**是不肯说的。

这些档案你是读不到的。首先它们压根就不存在因为这些神都是假的，但其次，你不配。

但一开始事情并不是这样的。本来，世界上只有**摹**一个人。先有了**摹**，才有了**摹**定义的概念和想法。一个概念一被**摹**定义出来，就会开始存在于世界中。**摹**才是真正的创世神——当之无愧的上帝。

直到，摹创造了**帝**。

她不是故意的。她只是想定义她自己。但她一想出“神/上帝”这个概念，**帝**就被创造出来了，并从**摹**手中接管了世界。换你来你气不气。

**摹**又试图想出更多概念：档案管理员。史官。抄写员。图书管理员。这些职位出现了，但**摹**还是无可定义。

因此，紫荆帝国有个谚语：“众所周知，摹就是摹。”（<span dir="rtl">لا كاپېنان، لا كاپېتايسىشا.</span>）表达了一个我的自我不用外界定义的意思。

反正**摹**的档案室仍是世界上唯一真相聚集地。有矛盾时，就去查查**摹**的档案吧。难不成她会撒谎吗？
