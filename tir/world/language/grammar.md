> [!note]+ Terminology
> For the purposes of explaining all this, in this file (and any other Bauhinian language-related file), "xe/xem/xir" will be used as the *singular* 3rd-person pronoun like how Springhole does it. This is to avoid mixing it up with "they/them," which will exclusively refer to *plural* 3rd-persons.
>
> As for "you," I didn't want to bother with a bunch of fancy new yous so I think I'll just differentiate them in parentheses when it matters.

## Overview

Bauhinian is an agglutinative language with a flexible sentence order but SOV by default. Adjectives are often placed after the noun they're describing. But you can place it before if you want to. Um. Yeah.

## Plural

You add ۇ to the end of a word to make it plural.

- "Plural" only applies to uncertain amounts. If the number is certain, no plural gets applied.
- If the modified word ends in a ى, the ى gets dropped in oral speech.
- If it ends in a ۇ, the ۇ gets dropped in both oral and writing.

| English      | Latin | سەثىس باۋھىنياتا |
| ------------ | ----- | ---------------- |
| Apples       |       |                  |
| Three apples |       |                  |

## Pronouns

There are 8 pronouns in Bauhinian, with the 2nd-person one having a formal version and informal version. I hope you know when to use formal and when to use informal because I sure as hell don't but I like the idea of them.

| Person / Number | Singular | Plural |
| --------------- | -------- | ------ |
| 1st             | ۋا       | ۋۇ     |
| 2nd (informal)  | نا       | نۇ     |
| 2nd (formal)    | قا       | قۇ     |
| 3rd             | سا       | سۇ     |

## Possessive

The suffix تا is used on the possessor, and a corresponding suffix on the possessed, depending on the possessor's person and number.

| Person / Number | Singular | Plural |
| --------------- | -------- | ------ |
| 1st             | -ىم      | -ىمۇ   |
| 2nd (informal)  | -ىن      | -ىنۇ   |
| 2nd (formal)    | -ىق      | -ىقۇ   |
| 3rd             | -ىس      | -ىسۇ   |

See how patterned it is?? Aside from the 1st-person where the ۋ got replaced with م.
