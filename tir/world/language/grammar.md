> [!note]+ Terminology
> For the purposes of explaining all this, in this file (and any other Bauhinian language-related file), "xe/xem/xir" will be used as the *singular* 3rd-person pronoun. This is to avoid mixing it up with "they/them," which will exclusively refer to *plural* 3rd-persons.
>
> As for "you," I didn't want to bother with a bunch of fancy new yous so I think I'll just differentiate them in parentheses when it matters.
