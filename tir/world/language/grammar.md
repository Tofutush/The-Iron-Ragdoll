## Overview

Bauhinian is an agglutinative language with a flexible sentence order but SOV by default. Adjectives are often placed after the noun they're describing. But you can place it before if you want to. Um. Yeah.

## Affix adding rules

- If a *suffix* is connecting to a vowel, the ى in the suffix gets dropped.
	- Most suffixes start with an ى.
- If an affix is being added to a word trunk, and the connecting letter from the *trunk* is an ى, then that ى gets dropped in *oral speech* but not written text.
- If the affix is the same as the letter it's connecting to, you only keep 1 letter in written text.

## Nouns

### Plural: ۇ

You add ۇ to the end of a word to make it plural. Always gets added first, before any other case marking.

"Plural" only applies to uncertain amounts. If the number is certain, no plural gets applied.

| English      | سەث |
| ------------ | ---------------- |
| Apples       | سەيتىن==ۇ==      |
| Three apples | پان سەيتىن       |
| Nights       | يامى==ۇ==        |
| Guns         | پاذۇ             |

### Pronouns

There are 5 pronouns in Bauhinian: one first-person, two second-person (formal and informal), two third-person (animate and inanimate). Each one also has a plural.

"Animate" includes people and things that are primarily made up of people, like countries and organizations (like the [ISA](/world/isa/) or the [MSS](/world/bauhinia/mss/)). In Fanton, the animate pronoun is usually used for plants and animals as well. Inanimate is just everything else. As you can see from the examples, "the Bauhinian language" is always translated as "سەثى==س==" and not "سەثى==ك==."

> [!note]+
> Do note that the people of TIR never say "Bauhinian language," as language to them is just language.

As for formal and informal, I hope you know when to use which because I sure as hell don't but I like the idea of them.

| Person / Number | Singular | Plural |
| --------------- | -------- | ------ |
| 1st             | ۋا       | ۋۇ     |
| 2nd (informal)  | نا       | نۇ     |
| 2nd (formal)    | قا       | قۇ     |
| 3rd (animate)   | سا       | سۇ     |
| 3rd (inanimate) | كا       | كۇ     |

### Possessive

The suffix تا is used on the possessor, and a corresponding suffix on the possessed, depending on the possessor's person and number. The owner, or just the possessor suffix on the owner, can be omitted if the context makes it clear.

| Person / Number | Singular | Plural |
| --------------- | -------- | ------ |
| 1st             | -ىم      | -ىمۇ   |
| 2nd (informal)  | -ىن      | -ىنۇ   |
| 2nd (formal)    | -ىق      | -ىقۇ   |
| 3rd (animate)   | -ىس      | -ىسۇ   |
| 3rd (inanimate) | -ىك      | -ىكۇ   |

See how patterned it is?? Aside from the 1st-person where the ۋ got replaced with م. Let's do some examples.

| English                           | سەث                          |
| --------------------------------- | ---------------------------- |
| My apple                          | سەيتىن==ىم== ۋا==تا==        |
| My apple (with the owner omitted) | سەيتىن==ىم==                 |
| The tree's apple                  | سەيتىن==ىك== ذام==تا==       |
| Bauhinian language                | سەث==ىس== لا باۋھىنيا==تا==  |
| Sparky's gun                      | پاذۇ==س== ئا بەربەرلېن==تا== |

#### Linking particle

You can also use "[owner] دې [owned]" to link them, in cases when it's not literally ownership.

| English               | سەث             |
| --------------------- | --------------- |
| Year of the cat       | مېيو دې كلىپسسو |
| The color of blood    |                 |
| The price of oblivion |                 |

These two are often interchangeable, though the former is more often used in daily speech and the latter can be more dramatic, as it is a relic straight from Ancient Bauhinian.

### Articles: ئا and لا

What was the "ئا" in front of Berberlën? That's the personal article, required before all people names. This is because Bauhinians like naming their children after things and there's no capitalization so it's clearer what's a name and what's not!

There's also an article for proper nouns that aren't people, لا. So to say Bauhinia, you say "لا باۋھىنيا." Gods are also referred to with لا.

### Markings

Or, stuff you can add to nouns.

#### Subject

To mark the subject. This is usually omitted, but it's نان for anyone who cares.

#### Object

To mark the object, i.e. the direct object of a verb. "I eat apples." The apple should be in the accusative case: ىپ.

| English       | سەث        |
| ------------- | ----------------------- |
| I eat apples. | ۋا سەيتىنۇ==پ== ئومنوم. |

#### Predicate

In English, predicates are what follows linking verbs. "I am Tofutush." "Sparky is cute." "She became a bodyguard." In Bauhinian, predicates have their own suffix to mark them.

The predicate marking needs to agree with the subject.

| Person / Number | Singular | Plural |
| --------------- | -------- | ------ |
| 1st             | -تايم    | -تايمۇ |
| 2nd (informal)  | -تاين    | -تاينۇ |
| 2nd (formal)    | -تايق    | -تايقۇ |
| 3rd (animate)   | -تايس    | -تايسۇ |
| 3rd (inanimate) | -تايك    | -تايكۇ |

Typically, in simple predicate sentences, the [subject marking](#subject) is often added.

| English                                   | سەث                            |
| ----------------------------------------- | ------------------------------ |
| I am Tofutush.                            | ۋا==نان==، ئا توفۇتۇش==تايم==. |
| Sparky is cute. (With nominative omitted) | ئا بەربەرلېن كۇتې==تايس==.     |

If you need to modify the sentences above with, say, [evidentiality or epistemic modality](#evidentiality-epistemic-modality), you can add that onto the predicate instead of the verb, as there is no verb.

## Verbs

### Evidentiality & epistemic modality

Evidentiality and epistemic modality are an important part of Bauhinian verbs. You add these suffixes on, evidentiality first and modality second.

They can both be omitted and assumed to be "assumption" and "confident" respectively (unless the evidentiality is "untrusted source"; then an omitted modality is assumed to be "neutral"), but in formal speech and documents you cannot omit anything. In novels and shows, the narration often leaves out both evidentiality and epistemic modality, but it's more common for 1st-person narration to be grammatically complete.

Evidentiality:

| English                                                              | سەث |
| -------------------------------------------------------------------- | ---------------- |
| Assumption / self-knowledge (trust me bro)                           | -ىۋا             |
| Universal ("as we all know…")                                        | -ىشا             |
| Experience (saw it with my own eyes)                                 | -ىنې             |
| Inference (inferred it from evidence)                                | -ىنا             |
| Trusted source (heard it from someone I trust)                       | -ىثۇ             |
| Untrusted source (heard it from someone I don't trust)               | -ىثە             |
| Dubious source (heard it from someone I'm not sure whether to trust) | -ىثو             |
| Direct source (heard it from the subject in question)                | -ىشۇ             |

> [!Note]+
> Note the last one: "heard it from the subject in question." This is used in contexts such as "Sparky told me she would eat dinner." If you want to express it, Bauhinians often say "Sparky would eat dinner" with the evidentiality of that. If it were "Sparky told me Nightsun would eat dinner," this stops being applicable (because Sparky isn't saying information about herself) and instead you either say the entire sentence, or say "Nightsun would eat dinner" with evidentiality set to however much you trust Sparky — though in the latter case you wouldn't be conveying that Sparky specifically told you that.

Epistemic modality:

| English                                          | سەث |
| ------------------------------------------------ | ---------------- |
| Total confidence (I'll kill myself if I'm wrong) | -ىژې             |
| Very confident (this must be the case)           | -ىما             |
| Confident (I'm pretty sure)                      | -ىتۇ             |
| Neutral (take it as you will)                    | -ىنە             |
| Unconfident (I'm not confident)                  | -ىگې             |
| Doubtful (this is prolly bullshit)               | -ىفو             |

> [!note]+
> The first one, total confidence, is only used in specific situations, such as swearing oaths at a wedding, or promising to tell the truth in court. It is not to be used lightly. You *are* expected to kill yourself if you're wrong.

### Deontic modality

Another type of modality is deontic modality, which are things like "must," "can," "should," and stuff. While epistemic modality expresses how confident the speaker is, deontic modality expresses obligation, permission, or ability and stuff.

Deontic modality is of course not required in speech, and are expressed as prefixes on verbs when present.

| English                 | سەث |
| ----------------------- | ---------------- |
| Must (high obligation)  |                  |
| Should (low obligation) |                  |
| May (permission)        |                  |
| Can (ability)           |                  |

### Tense

Tense is optional and described using adjectives.

### Habitual

Verbs in Bauhinian have no habitual aspect. To say "Nightsun spies on people," you have to say "Nightsun is a people-spier."

## Adjectives

In Bauhinian both nouns and verbs use adjectives to be described (so there aren't any adverbs).
